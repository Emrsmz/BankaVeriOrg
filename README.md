# BankaVeriOrg

A Python project that allows you to read, simplify, organize, categorize, and process transaction data from your bank/credit card statements in Excel or CSV formats.
#1 Get your data from your bank.
#2 Clone/pull the code into any Python environment.
#3 If your file is Excel: BaslatE("path/to/your/statement/file.xlsx")
#4 If your file is CSV: BaslatCSV("path/to/your/statement/file.csv")
#5 You can now perform your operations using the menu that appears on the screen.

Note: If your file is in .xls format, open it and use "Save As" to convert it to .xlsx format.


Hesap-Kart hareketlerindeki excel veya csv verileri okuma, sadeceleştirme, düzenleme ve kategorize etme ve bir çeşit işlem yapabilmenizi sağlayan python projem.

#1  Bankanızdan verileri alın.
#2 Herhangi bir python enviromentine kodları çekin.
#3 Dosyanız Excel ise : BaslatE(" Veri/Hareket Dosyanızın yolu .xlsx ")
#4 Dosyanız CSV ise : BaslatCSV(" Veri/Hareket Dosyanızın yolu .xlsx ")
#5 Karşınıza çıkan menü ile artık işlemlerinizi yapabilirsiniz.

Not: Eğer dosyanız ".xls" türünde ise içine girip save as ile ".xlsx" türüne çevirin.
